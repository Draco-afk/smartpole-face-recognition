# Smart Pole Web Application

เว็บแอปพลิเคชันของโครงงาน **ระบบจดจำใบหน้าบนเสาอัจฉริยะเพื่อนับคนเข้าออกและเฝ้าระวังบุคคล**

- **Backend:** FastAPI + SQLAlchemy (ค่าเริ่มต้น SQLite เปลี่ยนเป็น PostgreSQL ได้) + WebSocket
- **Frontend:** React (Vite)
- **ฐานข้อมูล:** 6 ตารางตาม ER Diagram ในบทที่ 3 ได้แก่ users, cameras, persons, face_embeddings, alerts, people_counts

## วิธีรัน (Windows)

1. ดับเบิลคลิก `start.bat` (ครั้งแรกจะติดตั้งทุกอย่างและสร้างข้อมูลตัวอย่างให้)
2. เปิด http://localhost:8000
3. ดับเบิลคลิก `run_simulator.bat` เพื่อจำลองกล้อง 3 ตัวส่งภาพและข้อมูลเข้ามา จะเห็นภาพสด ตัวเลขขยับ และการแจ้งเตือนพร้อมภาพเด้งขึ้นแบบเรียลไทม์
4. (ไม่บังคับ) ถ้ามีเว็บแคม ดับเบิลคลิก `run_webcam_demo.bat` แทนข้อ 3 กล้อง CAM 1 จะเป็นภาพจากเว็บแคมพร้อมตรวจจับใบหน้าจริงด้วย OpenCV

| executive | exec123 | แดชบอร์ด แจ้งเตือน ประวัติ รายงาน ดูรายชื่อเฝ้าระวัง |

## หน้าจอ

| หน้า | หน้าที่ |
|---|---|
| เข้าสู่ระบบ | ยืนยันตัวตนด้วย JWT แยกสิทธิ์ 3 ระดับ |
| ภาพสดจากกล้อง | ดูภาพสดทั้ง 3 กล้องพร้อมกัน (มีกรอบใบหน้า, Track ID, เส้นเสมือน) กดที่ภาพเพื่อขยาย บันทึกภาพ หรือดูเต็มจอ |
| แดชบอร์ด | จำนวนคนเข้า / ออก / อยู่ในพื้นที่, กราฟรายชั่วโมง (เข้าอยู่เหนือเส้น ออกอยู่ใต้เส้น), สถานะกล้อง 3 ตัว, แจ้งเตือนล่าสุด, เลือกดูวันย้อนหลังได้ |
| การแจ้งเตือน | รายการที่ยังไม่ได้รับทราบ กด "รับทราบ" แล้วรายการจะหายจากหน้าจอของทุกคนพร้อมกัน |
| ประวัติการตรวจพบ | ค้นหาตามชื่อ ประเภท กล้อง สถานะ และช่วงวันที่ |
| รายงาน | สรุปรายวัน กราฟ ตาราง และดาวน์โหลด CSV (เปิดใน Excel แล้วอ่านภาษาไทยได้) |
| รายชื่อเฝ้าระวัง | เพิ่ม / แก้ไข / ลบ บุคคล Blacklist และ VIP พร้อมอัปโหลดรูปใบหน้า |
| กล้อง | ตั้งชื่อ ตำแหน่ง ทิศทาง RTSP URL และดูสถานะออนไลน์ |
| ผู้ใช้งาน | จัดการบัญชีและสิทธิ์ |

การแจ้งเตือนใหม่จะแสดงเป็นแถบด้านบนของทุกหน้าพร้อมเสียง โดยใช้สีแดงสำหรับ Blacklist และสีทองสำหรับ VIP
ทุกการแจ้งเตือนเก็บภาพไว้ 2 ภาพ คือภาพใบหน้าที่กล้องจับได้ และภาพเต็มจากกล้องขณะตรวจพบ กด "ดูภาพเหตุการณ์" เพื่อเทียบกับรูปที่ลงทะเบียนไว้

## เชื่อมต่อกับระบบ AI จริง

ระบบ AI (YOLO + ByteTrack + โมเดล Embedding) ส่งข้อมูลเข้ามาทาง API โดยใส่ header `X-API-Key` และใช้ `backend/pipeline_client.py` ได้เลย

| Endpoint | ส่งเมื่อ |
|---|---|
| `POST /api/ingest/frame/{camera_id}` (body = ภาพ JPEG) | ทุกเฟรม 5–10 fps ส่งภาพที่วาดกรอบแล้ว เพื่อแสดงภาพสดบนเว็บ |
| `POST /api/ingest/heartbeat` `{camera_id}` | ทุก ~10 วินาทีต่อกล้อง (ใช้แสดงสถานะออนไลน์) |
| `POST /api/ingest/count` `{camera_id, direction: "in"/"out", track_id}` | เมื่อ Track ข้ามเส้นเสมือน |
| `POST /api/ingest/face` `{camera_id, track_id, embedding: [...], snapshot_b64?, frame_b64?}` | เมื่อยืนยันใบหน้าได้ ระบบจะคำนวณ Cosine Similarity กับฐานข้อมูลให้เอง และแจ้งเตือนเมื่อค่าคล้าย ≥ `MATCH_THRESHOLD` |
| `POST /api/ingest/embedding` `{person_id, embedding}` | ลงทะเบียนเวกเตอร์ใบหน้าของบุคคลในรายชื่อ |
| `GET /api/ingest/watchlist` | ดูว่าบุคคลใดมีรูปแล้วแต่ยังไม่มีเวกเตอร์ |

เอกสาร API แบบโต้ตอบได้อยู่ที่ http://localhost:8000/docs

**ทำไมไม่เปิด RTSP บนเว็บโดยตรง:** เบราว์เซอร์เล่น RTSP ไม่ได้ และภาพดิบจากกล้องไม่มีกรอบใบหน้า ระบบจึงให้ฝั่ง AI (ซึ่งเปิด RTSP อยู่แล้ว) ส่งภาพที่ประมวลผลแล้วมาที่ Backend จากนั้น Backend กระจายภาพไปยังทุกหน้าจอผ่าน WebSocket (`/ws/video`) ใช้การเชื่อมต่อเดียวต่อหน้าจอ ไม่ว่าจะดูกี่กล้อง

> **หมายเหตุ:** `simulator.py`, `demo/scene.py` และ `app/fakevec.py` ใช้ภาพวาดและเวกเตอร์สุ่มแทนกล้องและโมเดลจริงเพื่อการสาธิตเท่านั้น โหมดเว็บแคมตรวจจับใบหน้าจริงด้วย Haar Cascade ของ OpenCV แต่ยังไม่ได้จดจำตัวบุคคลจริง (`--webcam-as` เป็นการกำหนดให้ใบหน้านั้นเป็นบุคคลในรายชื่อ) เมื่อเชื่อมโมเดลจริงแล้ว ข้อมูลใน `seed.py` ควรถูกแทนด้วยการลงทะเบียนจากรูปจริง

## การตั้งค่า (environment variables)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `DATABASE_URL` | `sqlite:///backend/smartpole.db` | เช่น `postgresql+psycopg://user:pass@localhost/smartpole` |
| `JWT_SECRET` | (ค่าทดสอบ) | **เปลี่ยนก่อนใช้งานจริง** |
| `PIPELINE_API_KEY` | `smartpole-pipeline-key` | **เปลี่ยนก่อนใช้งานจริง** |
| `MATCH_THRESHOLD` | `0.45` | ค่าขีดแบ่ง Cosine Similarity |
| `ALERT_COOLDOWN_SEC` | `300` | ไม่แจ้งเตือนบุคคลเดิมซ้ำภายในเวลานี้ |
| `CAMERA_OFFLINE_SEC` | `60` | ไม่ได้รับ heartbeat นานเกินนี้ถือว่ากล้องออฟไลน์ |
